# الأمان

- استخدم مفاتيح Demo بصلاحية تداول مناسبة وملفًا محليًا محدود الصلاحيات. تُستثنى ملفات الأسرار والحالة والدفاتر من Git.
- Paper وShadow يستعملان بيانات سوق عامة، وواجهة Shadow خادم قراءة محلي. لا تشغّل الخوادم المحلية على عنوان عام.
- طبقة تنفيذ Apex ترفض Mainnet وعنوان Demo غير المعتمد قبل إنشاء عميل الطلبات.
- ضع ملفات التقاط السوق والحسابات والتقارير الخاصة داخل `runtime/`. استخدم `python tools/audit_secrets.py` لمراجعة الأنماط، وراجع أي نتائج قبل النشر.
- قفل حالة Demo يحمي مجلد الحالة المحلي. شغّل نسخة واحدة لكل حساب، خصوصًا عند اختلاف المجلد أو الجهاز.
