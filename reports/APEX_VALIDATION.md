## شروط القبول المتبقية

- **PENDING** جمع depth/trade tape صالح مع تغطية تمويل، بناء عينات تدريب سوقية، ومقارنة خارج العينة لكلا النظامين على أحداث متطابقة.
- **PENDING** تقييم أثر Regime والوقف المتكيف وحجم المخاطرة عبر فترات مستقلة. لا توجد بيانات كافية لإثبات أفضلية أو Sharpe.
- **PENDING** ملء جزئي في Replay، وتجربة partial exit، وربط محفظة ومخاطر Apex بطبقة Demo الدائمة. تنفيذ Binance الموروث اختُبر محليًا.
- **PENDING** soak فعلي على Demo، وقياس موارد Termux واستعادة الاتصال على جهاز حقيقي.
- **PENDING** منع تشغيل النسخة نفسها على الحساب الواحد عبر أجهزة مستقلة أو مفاتيح مختلفة. يوجد قفل لمجلد الحالة المحلي.
- **BLOCKED** رصد WebSocket العام حيًا من بيئة الاختبار الحالية.
- **BLOCKED** ربط التاريخ الأصلي بـ Apex عبر GitHub API. الفرع المرجعي المطابق محفوظ ببصمة Git tree المصدر.
