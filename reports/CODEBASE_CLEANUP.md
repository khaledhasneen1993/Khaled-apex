# تدقيق التنظيف

قبل التعديل فُحصت شجرة الملفات، ومراجع وحدات التنفيذ والتشغيل والاختبارات والنشر. سجل المرشحين:

| المرشح | الإجراء والدليل |
| --- | --- |
| `exchange.rollout.require_mainnet_readiness` | أزيلت الدالة غير المستدعاة. بحث النص في ملفات Python وجد تعريفها فقط. تمنع طبقة LiveExchange إنشاء عميل Mainnet قبل إرسال الطلبات |
| معادلة حجز الهامش المكررة في `research/replay.py` و`apex/order_manager.py` | وُحدت في `OrderManager.required_margin`. يختبر Property-Based الحجز لأربع فرص وتطابق سجل إعادة التشغيل |
| الحظر الدائم لمسار التأهيل | استُبدل بمسار مقيد ذي موافقة وقفل حساب وفحص قراءة جديد. بقي اعتماد التشغيل المستمر منفصلًا |
| `tools/upgrade_demo_policy.py` و`run_paper_live.py` وأدوات الحالة | احتُفظ بها بسبب مراجع الاستعادة والاختبارات والتوافق والنشر |
| تقارير OHLCV وChampion Baseline | احتُفظ بها كأدلة تاريخية للمقارنة، مع فصل نتائج المحاكاة |

حذف الملفات المتتبعة: صفر. لم تُحذف حالات حساب أو دفاتر أو WAL أو اختبارات انحدار. تُذكر نتائج الاختبارات في تقرير التحقق.
